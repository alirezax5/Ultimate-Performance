# Ultimate Performance

**پلاگین کشینگ حرفه‌ای وردپرس با کش صفحه‌ی بدون-PHP و کش آبجکت با فیلوور ایمن**

## معرفی

Ultimate Performance یک پلاگین کامل کارایی وردپرس است که شامل کش صفحه، کش آبجکت با پشتیبانی از Redis/Memcached/APCu/SQLite/File، باطل‌سازی هوشمند کش، سازگاری با WooCommerce، و یکپارچگی وب‌سرور می‌باشد.

## امکانات

- **کش صفحه (Page Cache)**: پاسخ‌های کش‌شده بدون اجرای PHP
- **کش آبجکت (Object Cache)**: Redis، Memcached، APCu، SQLite، File
- **باطل‌سازی هوشمند**: پاکسازی هدفمند کش هنگام تغییر محتوا
- **سازگاری با WooCommerce**: تشخیص ایمن صفحات عمومی و خصوصی
- **حفاظت از محتوای خصوصی**: جلوگیری از کش صفحات سبد خرید، تسویه حساب و حساب کاربری

## نصب

1. فایل ZIP پلاگین را در `wp-content/plugins/` آپلود کنید
2. از پنل مدیریت وردپرس، پلاگین را فعال کنید
3. به تنظیمات → Ultimate Performance بروید
4. کش صفحه را فعال کنید

## پیکربندی

### کش صفحه
- **TTL**: مدت زمان ماندگاری کش (پیش‌فرض: ۳۶۰۰ ثانیه)
- **SWR**: سرو محتوای قدیمی هنگام تولید کش جدید

### کش آبجکت
- **بک‌اند**: Redis (توصیه‌شده)، Memcached، APCu، SQLite، File
- **پیشوند**: پیشوند اختصاصی برای جداسازی کش سایت

### Redis
- **Host**: آدرس سرور Redis (پیش‌فرض: 127.0.0.1)
- **Port**: پورت Redis (پیش‌فرض: 6379)
- **Database**: شماره دیتابیس Redis
- **TLS**: فعال‌سازی رمزنگاری

## امنیت

- صفحات خصوصی (سبد خرید، تسویه، حساب کاربری) هرگز کش نمی‌شوند
- محتوای کاربران واردشده از کش مستثنی است
- Nonce‌های امنیتی شناسایی و مسدود می‌شوند

## باطل‌سازی کش

رویدادهای پاکسازی خودکار:
- ایجاد/ویرایش/حذف پست، صفحه و محصول
- تغییر قیمت، موجودی و عنوان محصول
- تغییر وضعیت محصول (انتشار، پیش‌نویس، خصوصی، سطل زباله)

## نیازمندی‌ها

- وردپرس 6.0 یا بالاتر
- PHP 8.1 یا بالاتر
- (اختیاری) Redis یا Memcached برای کش آبجکت
